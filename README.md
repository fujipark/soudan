# 学生相談室 予約管理 (PHP版)

「学生相談室予約表.xlsm」(Excel + VBA)を PHP + PDO に移植したものです。
動作確認済み: PHP 8.3 / SQLite。MySQL は未検証です(下記)。

## セットアップ

```bash
php bin/install.php            # テーブル作成・マスタ初期値登録・ログインパスワード設定(8文字以上)
php -S 127.0.0.1:8000 -t public   # 開発用サーバー → http://127.0.0.1:8000/
```

- 本番では Web サーバーの公開ディレクトリを `public/` にしてください(`data/` と `config.local.php` を公開しないため)。
- 学生の相談記録を扱うので、必ず HTTPS で運用してください。
- MySQL にする場合は `config.php`(または `config.local.php`)の `db_dsn` / `db_user` / `db_pass` を変更して
  `php bin/install.php` を実行します。テーブル作成は MySQL 用の記述も含みますが、**MySQL では未検証**です。
- Excel からの移行は CSV 取込(管理画面、または `php bin/import_csv.php ファイル.csv`)。
  列は `日付,担当,時間,学籍番号,来談,状況,学年,学科,相談内容,家族相談,連携,経緯,卒業生,備考`(UTF-8)。

## 意図的に変えた点

- 日付行の事前作成(うるう年用の「うるう用」16行や、月ごとの開始行番号の固定配列)は廃止。枠は画面で動的に作ります。
- 学籍番号の自動コピーは、**その行の来談〜経緯がすべて空のときだけ**行います(元は入力済みでも上書き)。
- 整合性チェックの「家族なし/連携なし/経緯なし」は、エラーではなく「確認」(任意項目)として分けて表示します。
- 前年度から継続の学生は、1回目の記録が「初回」でなくてもエラーにしません(逆に「初回」ならエラー)。
- 実人数の計算は SQL の `COUNT(DISTINCT 学籍番号)`(学科・学年ごと)。元のように学籍番号の空欄は数えません。
- 集計２表の表3〜6は、同じ集計軸のクロス集計として汎用化しました。**レイアウトは元の表と完全には一致しません**。
- ログインは共通パスワード1つです。担当者ごとのアカウントや操作履歴は入れていません。

## VBA を読んで気づいた点(要確認)

- 集計シートの「初回」件数の条件が `こども発達`(ひらがな)になっていますが、マスタの学科名は `子ども発達` です。
  Excel の COUNTIFS は表記ゆれを吸収しないため、この学科の初回数は元の表では常に0になっていた可能性があります。
  PHP版はマスタの名称で集計するので、この点は正しい値になります(過去の集計と数字が食い違う場合の原因候補です)。
- 集計処理の多くは「数式を文字列で組み立ててセルに書く」処理で、同じコードが「集計」「集計２表」系の別シートにも重複していました。
  業務ロジックとしては上の対応表の範囲です。
